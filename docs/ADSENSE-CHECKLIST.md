## 0. Перед подачей — трезвая оценка
- [ ] Сайту хотя бы несколько недель, есть история и ХОТЬ КАКОЙ-ТО органический трафик
      из поиска (не только заходы владельца). Нулевой трафик + свежий домен = частая
      причина вердикта «Бесполезный контент».
- [ ] Основной домен, не поддомен бесплатного хостинга; собственный домен, HTTPS.

## 1. Контент (главная причина отказов)
- [ ] 20–30+ полноценных статей МИНИМУМ (лучше больше), каждая уникальная и полезная.
- [ ] Объём: разборы 800–2000+ слов; не «заглушки» в 100 слов.
- [ ] Оригинальность: не копипаст, не рерайт, не автоген «для объёма».
      Google 2024+ жёстко бьёт по scaled/AI-массовке — контент должен нести ценность.
- [ ] Единая понятная ниша/тема сайта (а не «всё обо всём»).
- [ ] Нет «страниц-заглушек», «under construction», пустых рубрик, Lorem ipsum.
- [ ] YMYL (здоровье/финансы/право): выше планка экспертности — источники,
      факты, дисклеймеры, по возможности указанное авторство/экспертиза.
- [ ] Свежесть: часть материала обновляется, видны даты.

## 2. Обязательные страницы (и в меню/футере, доступны с любой страницы)
- [ ] Privacy Policy — с явным упоминанием Google/AdSense, сторонних cookie,
      DoubleClick и ссылкой на настройки рекламы. (Без этого — почти автоотказ.)
- [ ] About / О сайте — кто вы, о чём проект, зачем.
- [ ] Contact / Контакты — реальный способ связи (форма или email).
- [ ] Terms / Условия использования.
- [ ] (Плюс к E-E-A-T) Редакционная политика / авторы, Disclaimer.

## 3. Технические требования
- [ ] ads.txt в корне: `google.com, pub-5535516142831006, DIRECT, f08c47fec0942fa0` (HTTP 200).
- [ ] Код AdSense (adsbygoogle.js с вашим client) стоит на всех страницах И виден
      боту (не за JS-гейтом, не только в консоли).
- [ ] Сайт подключён в интерфейсе AdSense, статус «Проверка».
- [ ] HTTPS везде, http→https редирект; www/apex приведены к одному канону (301).
- [ ] Адаптив/мобайл: сайт корректен на телефоне.
- [ ] Скорость/Core Web Vitals в норме (сжатые картинки WebP/AVIF, кэш).
- [ ] Рабочая навигация: меню, внутренние ссылки; НЕТ битых ссылок и 404 в меню.
- [ ] sitemap.xml + robots.txt; сайт индексируется (проверить в Search Console).
- [ ] Нет всплывающих окон/редиректов/обмана, тяжёлой сторонней рекламы поверх контента.

## 4. Политика и чистота
- [ ] Нет запрещёнки: пиратство, взрослый контент, оружие/наркотики, «чудо-лекарства»,
      разжигание, кликбейт-обман, накрутка.
- [ ] Нет чужого контента без прав (тексты, фото — свои или по лицензии, с атрибуцией).
- [ ] Явно понятно, чей это сайт и что он делает.
- [ ] На время модерации не показывать пустые AdSense-блоки (либо свои заглушки/
      house-ads, либо не выводить юнит, если сеть ещё не отдаёт).

## 5. Частые причины отказа → что чинить
- [ ] «Low value content / Бесполезный контент» → больше оригинальной пользы,
      чёткая ниша, убрать тонкие страницы (или закрыть их noindex), нарастить трафик.
- [ ] «Site not ready / under construction» → убрать заглушки, довести навигацию.
- [ ] «Insufficient content» → добавить статей, не выкладывать полупустой сайт.
- [ ] Нет Privacy/Contact → добавить (см. п.2).
- [ ] ads.txt отсутствует/неверный → исправить.

## 6. Подача и после
- [ ] Подавать, когда сайт реально «живой»: контент + немного трафика + все страницы.
- [ ] Никогда не кликать по своим объявлениям, не просить кликать.
- [ ] Отказ ≠ бан: чинишь замечания и подаёшь снова (бесплатно). Ответ обычно
      от пары дней до 2 недель.
- [ ] AdSense — бонус к монетизации; партнёрки/прямая реклама от него не зависят.
