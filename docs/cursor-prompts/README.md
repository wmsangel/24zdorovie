## Чего здесь намеренно нет

- **IG-хэндлы в слайды/хаб** (`→cursor`, соц-хвост) — в репо нет плейсхолдеров: слайды
  (`social/scripts/social-slides.mjs`) и `posts.js` хэндлы не рендерят, а в подписи
  (`telegram-daily.mjs`) уже стоят финальные `@zdorovie24ru`/`@zdorovie24en`. Хаб — артефакт,
  не репо-файл. Репо-поверхности для Cursor нет; промт появится, только если владелец решит
  добавить хэндл-футер в сами слайды (это уже `→сам`, дизайн-решение).
- **#9 ревизия «ответ-первым»** (`→гибрид`) — ждёт конкретные статьи, которые отметит жена
  владельца (реальный сигнал). Без списка флагов образца для тиражирования нет.
- Пункты `→сам` (#1 sleep-вотч, #3 щитовидка, #5 CTR по дельте, #6 детская тема, #7 AdMob,
  #8 Paddle) — судейские/контентные, под Cursor не выносятся.
