## ⚡ Частые команды

```bash
npm run dev          # локально: localhost:3000
npm run build        # прод-сборка в out/ (проверяет все статьи)
npm run deploy       # собрать и залить изменившееся + сбросить кэш Cloudflare
npm run deploy:dry   # показать, что уехало бы, ничего не отправляя
npm run indexnow     # пинг Bing + Yandex о страницах
npm run traffic      # разбор трафика Cloudflare (боты, браузеры, коды)
npm run tg:status    # очередь автопостинга в Telegram
npm run tg:dry       # показать посты, ничего не отправляя
```

> Деплой иногда разово падает на сборке (воркеры `next build` на ~1200 страниц) —
> лечится повторным `npm run deploy`.

## 🗺️ Где что менять (карта конфигов)

| Задача | Файл |
| --- | --- |
| Добавить статью | `content/{locale}/{category}/{slug}.mdx` |
| Служебные страницы (about, privacy, contacts…) | `content/pages/{locale}/{slug}.mdx` |
| Рубрики + пиллар-вступления | `src/config/categories.ts` |
| Инструменты (калькуляторы) | `src/config/tools.ts` + компонент в `src/components/tools/` + `registry.tsx` |
| Реклама, сети, домовые кросс-промо баннеры | `src/config/ads.ts` |
| Партнёрские офферы под калькуляторы | `src/config/offers.ts` |
| SEO: schema.org, мета, hreflang | `src/lib/seo.ts` |
| Домен, соцсети, аналитика, рассылка | `src/config/site.ts` |
| Редиректы, заголовки, кэш, MIME | `public/.htaccess` |
| OG-картинки и favicon (перезаписываются сборкой) | `scripts/gen-og.mjs`, `src/app/icon.svg` |
